# M1 — Memory, Interrupts and Time

**Status:** NOT STARTED. The next milestone.

## Objective

Take full ownership of the machine's memory and interrupt architecture: Malrynth-managed page
tables, a physical frame allocator, a kernel heap, exception and interrupt handling, a
calibrated timer, and secondary-CPU bring-up.

## Dependencies

M0 (the memory map and framebuffer arrive via `BootInfo`).

## Scope

- Physical frame allocator over the M0 memory regions.
- Malrynth-owned 4-level page tables; move the kernel to the higher half
  (`0xFFFF_FFFF_8000_0000`), which retires `KERNEL_PHYS_BASE`.
- W^X mapping using the existing per-segment `PT_LOAD` permissions.
- Kernel virtual address space layout, including a physical-memory direct map.
- Kernel heap and `alloc` support.
- GDT, IDT, TSS; exception handlers with diagnostic dumps; a dedicated double-fault stack.
- APIC and I/O APIC; interrupt routing.
- TSC calibration and a monotonic clock; a periodic timer.
- ACPI table discovery from the RSDP captured in M0 — only as far as MADT for CPU/APIC
  enumeration.
- SMP bring-up; per-CPU data; replace `static mut COM1` with a proper lock.
- Boot-time instrumentation, enabling the first real boot-time budget.

## Explicitly out of scope

User mode, processes, threads, scheduling, syscalls, capabilities, IPC, drivers beyond the
timer and interrupt controller, filesystems, networking, graphics.

## Exit criteria

- The kernel executes from the higher half under its own page tables.
- The frame allocator satisfies and releases allocations without corrupting the map, verified
  against the M0 region list.
- A deliberately triggered page fault and double fault produce a correct diagnostic dump
  rather than a triple fault.
- The timer produces a monotonic clock with measured drift under QEMU.
- All CPUs reported by the MADT reach an idle loop.
- Boot time is measured and recorded with an in-kernel timestamp.
- `MALRYNTH_M1_BOOT_OK` emitted after SMP bring-up.

## Tests

Frame-allocator unit tests on the host; in-kernel self-tests for paging invariants;
fault-injection tests for each exception class; a multi-CPU rendezvous test; existing M0
tests continue to pass unchanged.

## Performance gates

First real boot-time budget. Frame allocation and page-map operation costs measured.
M0 image-size ceilings enforced in CI from this milestone.

## Security gates

W^X enforced for kernel mappings; guard pages around kernel stacks; no writable-executable
mapping anywhere; the unsafe inventory in `UNSAFE-RUST-POLICY.md` updated for page-table and
allocator code.

## Documentation required

`docs/architecture/MEMORY-MODEL.md`; ADR for the virtual address space layout; ADR if a
custom target JSON becomes necessary for `code-model = "kernel"`; threat-model revision.
