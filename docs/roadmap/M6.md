# M6 — Graphics, Input and Media

**Status:** NOT STARTED. **Depends on:** M5. Years from M0.

## Objective
A Malrynth-native graphical system: GPU drivers, a Vulkan-first stack, a native compositor,
input, audio, and the accessibility foundation.

## Scope
GPU driver framework and at least one real GPU driver; Vulkan as the primary graphics API;
the native Malrynth compositor and its display protocol; input routing; audio with a measured
low-latency path; a media pipeline; text shaping and rendering; the accessibility foundation
— designed in from the start, because retrofitted accessibility is invariably poor.

## Explicitly out of scope
Applications (M7), a full toolkit, compatibility layers.

## Exit criteria
The compositor presents at the display's refresh rate with a measured frame-time
distribution; input-to-photon latency measured; audio round-trip measured; accessibility APIs
exist and are exercised by a real client.

## Gates
**Performance:** frame time, dropped frames, input-to-photon, audio round trip — all
user-visible and all tracked.
**Security:** GPU drivers are unprivileged and IOMMU-confined; the compositor mediates input
and screen capture as capabilities, because screen and input access are among the most
sensitive capabilities in a desktop system.

## Documentation
Compositor and display protocol specifications; graphics architecture ADRs; accessibility
architecture. **Whether `ui/` earns its own repository is re-evaluated here** against ADR-0001.
